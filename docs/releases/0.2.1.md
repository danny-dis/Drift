# Drift 0.2.1

A maintenance release focused on first use, truthful runtime status and safe thought processing. Your existing box and exact saved originals are retained; generated suggestions remain advisory and unverified.

## Easier first use

- A Getting started guide separates saving readiness from optional AI readiness, explains where thoughts and drafts live, and states when processing can involve a remote provider.
- An explicit **Check AI connection** requests one short real reply under the existing provider policy and per-box call allowance. Opening the dashboard or refreshing setup status does not call a model. A previous successful check is not a promise of future availability.
- Optional Drift API token settings are collapsed unless authentication is required. Saving settings refreshes status and history without clearing the draft.
- Empty drafts have neutral copy, mobile capture is more compact, and tabs support arrows/Home/End with matched panel identifiers and visible keyboard focus.
- Project map selections resolve real project IDs instead of selecting disconnected placeholders. Project loading and research repair feedback remain visible and honest.

## Correct wiring and bounded work

- The Attention endpoint calls the real candidate generator; an unavailable request is no longer disguised as an empty queue.
- Candidate deduplication uses persisted idea identities and attention markers, including long ideas, blocked tasks and restarts. Blocking is not bypassed by spawning a replacement task.
- `/api/ui/usage` reads canonical persisted call accounting rather than an unused in-memory tracker. Calls use current-day/week scopes; recorded failures and known cost estimates have lifetime scopes. Unsupported success/capability/provider breakdowns are unavailable rather than invented zeros.
- Corrupt call accounting does not pretend there were no calls or reopen inference admission.

## Better thought context

- Captured-thought inference receives the current original part separately from processing/privacy instructions and unrelated historical events, memories and pending signals.
- The instructions explicitly preserve the original subject and uncertainty. Privacy remains a valid subject when the original itself discusses it.
- Credential filtering still derives from the complete canonical original before slicing; captured text is not rewritten.
- A canonical part that cannot safely fit the configured context budget stops for review before a model call. It is not silently shortened and marked processed.

## Reliability, security and build hygiene

- FastAPI lifespan management tracks and cancels both initial and API-created organism tasks, including delayed startup. Deprecated application event hooks are removed.
- Backup restore uses Python's safe data filter and rejects paths/links that escape the target folder.
- Removed the unmounted legacy frontend App and unused sprite definitions. The explicitly tested GameWorld compatibility wrapper remains.
- The frontend build selects production React regardless of an inherited development NODE_ENV. Its small executable build contracts run in CI.
- Hosted CI installs and builds frontend dependencies before executable UI regression tests, then verifies the Python artifacts outside the checkout.

## Install

Use Python 3.12 or 3.13; Node is not required for the installed wheel.

```sh
python -m pip install "https://github.com/danny-dis/Drift/releases/download/v0.2.1/drift-0.2.1-py3-none-any.whl"
python -m drift.main --box ./drift_box --name Drift
```

Open `http://localhost:47116`. Keep the terminal running; Ctrl+C stops the service.

Saving and searching work without an AI gateway. The default optional inference route uses a separately running local DMR-X gateway at `http://127.0.0.1:47113/v1` with `auto-free`. Drift does not install or restart DMR-X. Free-only enforcement has no silent paid fallback; external availability and rate limits remain outside Drift's control.

If the server requests a Drift API token, use Connection settings. Never put a provider credential in that field. Keep the bind address local; local-first saving does not imply local-only inference or guarantee that all private data is filtered.

## Upgrade and rollback

1. Stop Drift, not the gateway, and back up your existing box folder.
2. Install this wheel, preferably in a new virtual environment.
3. Start it with the same absolute `--box` path and the desired port.
4. Confirm saved originals and inspect any work awaiting review before approving it.

No destructive data migration is required. A package rollback does not reverse every application-state change; keep the box backup. The release includes a wheel, source distribution, frontend ZIP and SHA256SUMS. The ZIP is UI assets, not a standalone backend; dependencies still require installation.

## Verification and limits

Publication is gated on Windows/Linux Python 3.12/3.13 checks, the production frontend build, regression tests and clean wheel installation. Release acceptance separately exercises real inference, source-backed research, browser/mobile/keyboard behavior, interruption/retry, explicit approval recovery and restart persistence in disposable boxes.

AI output still needs human review. Retaining valid citations is not independent factual verification, and no test suite certifies month-long unattended usefulness, clinical benefit, arbitrary scale or third-party service uptime. This release is published through GitHub assets, not PyPI.
