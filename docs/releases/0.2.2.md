# Drift 0.2.2

This patch makes Drift easier to use each day and safer to recover when something fails. Keep your existing box when you upgrade; your original thoughts and call accounting stay with it.

## What changed

The optional local supervisor can restart a failed worker, report whether background work is alive and rotate its logs. It refuses duplicate starts against the same box. Existing blocked tasks still need your approval, and restarts do not reset call allowances.

The Inbox, Projects, Research and approval screens use simpler labels. Saved suggestions are easier to open, while technical details stay available behind disclosure controls.

The Office panda now follows reported task activity. It distinguishes a lost connection from idle time and labels saved work honestly. Walking and desk/couch poses have regression checks. The animation remains an illustration, not an extra coding agent.

Provider errors no longer write response bodies or full exception messages to logs, including failures after a tool call. Research updates also serialize across separate processes, with locks that release when a process exits.

The test fixes include isolated lifecycle timing fakes, portable Windows/Linux paths and discovery of every frontend regression script.

## Install or upgrade

Use Python 3.12 or 3.13:

```bash
python -m pip install --upgrade "https://github.com/danny-dis/Drift/releases/download/v0.2.2/drift-0.2.2-py3-none-any.whl"
python -m drift.main --box ./drift_box --name Drift
```

Open http://localhost:47116. Back up your box first, pass the same path as before and do not run two services against it. The wheel includes the dashboard, so Node.js is not required to use the release. See [the supervisor guide](../local-runtime.md) for source installations that need automatic restarts.

## Verification and limits

The release passed 724 Python tests in each Windows/Linux and Python 3.12/3.13 CI job, plus 13 frontend checks. Acceptance covered a clean wheel installation, browser use and a real AI reply that survived restart without another call or a duplicate thought.

Saving and searching work without AI. Suggestions need a reachable provider and consume the existing allowance. Review the output: citations are not fact checking, and a passing test suite cannot guarantee useful answers or long unattended operation.
