# Drift 0.2.2

A reliability and everyday-use patch. Existing boxes, original thoughts, call accounting and provider settings remain compatible; keep using the same `--box` path.

## Changes

- Add an opt-in local supervisor with single-instance box/worker locks, authenticated worker-liveness monitoring, bounded restart/backoff, optional local gateway recovery and rotating logs. A reachable HTTP page is no longer confused with a live background worker.
- Keep owner-queued work ahead of optional planning and preserve named systems, dependencies and the distinction between proposed and verified capabilities in capture instructions.
- Remove prompt/message summaries, provider response bodies, credential-bearing URLs and exception messages from provider error logging.
- Make the Inbox, Projects, Research, saved suggestions and approval flows easier to read. Keep advanced technical details available without making them the default screen.
- Connect the Office companion to actual task/project activity, distinguish offline from idle, show only real recent saves, and improve obstacle-aware walking and desk/couch poses. It remains an illustration, not an autonomous coding workforce.
- Preserve the earlier research worker's cross-process writer exclusion using a bounded OS-backed lock that releases on process exit. Concurrent updates retain sources and revisions; stale directory locks do not block restarts.
- Run all frontend regression scripts in the normal test command. Scope lifecycle test fakes to the server module so they cannot replace AnyIO's scheduling primitives.

## Install or upgrade

Use Python 3.12 or 3.13:

```bash
python -m pip install --upgrade "https://github.com/danny-dis/Drift/releases/download/v0.2.2/drift-0.2.2-py3-none-any.whl"
python -m drift.main --box ./drift_box --name Drift
```

Open http://localhost:47116. Use the same box as before; do not start two services on that box. Back up the box before upgrading. The wheel includes the dashboard; Node.js is not required to use it.

For supervised source operation, see [local runtime](../local-runtime.md). Supervision is optional and is not an operating-system sandbox or a 24-hour reliability guarantee. Existing budgets and blocked tasks are not reset or silently approved.

## Boundaries

Saving and searching work without AI. AI suggestions require a reachable, configured inference provider and consume the existing call allowance. Free-only policy, shell-off defaults, loopback binding, origin checks, approvals, source provenance and human review remain in place. Research citations are not independent fact checking.

Historical worker edits were reconciled by intent rather than copied wholesale over newer fixes. Private logs, old task/review notes and superseded source versions are retained in the operator's verified backup, not published in the release.
