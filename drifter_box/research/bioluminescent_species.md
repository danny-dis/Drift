# Bioluminescent Species Catalog

## Example Species
- **Mycena chlorophos** – Small night‑glowing mushroom; habitat: tropical forests.
- **Panellus stipticus** – Bioluminescent fungus on decaying wood; emits green light.
- **Omphalotus olearius** – Bright orange caps; known for intense luminescence.

## Catalog Format
- Scientific name
- Common name (if any)
- Habitat description
- Light color/pattern
- Notes on ecology or behavior
