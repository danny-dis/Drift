# Drift v0.2.1: beginner-friendly verified release

User authorization: fix every issue found in live QA, run more live tests, push and publish v0.2.1. Existing v0.2.0 plan/checklist are retained; this is the next release, not an overwrite.

## Design contract

The primary task remains saving an exact thought immediately. Guidance must never block saving or demand categorization. Show separate storage readiness and AI readiness; a real one-call connection check is explicit, bounded and accounted. Never present an unchecked provider as ready. Connection/token configuration belongs in a collapsible settings area unless authentication is needed. Desktop and 320/390/768/1024/1440px layouts remain readable. Tabs support arrows/Home/End and tab-panel linkage. Every empty/error/loading/result state is honest.

## Ordered acceptance slices

- [ ] Attention: correct real generator; honest outage UI; no new qualification tasks for an idea already represented by persisted task identity or attention dedup marker. Pending/blocked/completed work survives restart without duplication.
- [ ] Usage: canonical per-box persisted counters, explicit daily/week/lifetime/estimated-cost scopes; missing/corrupt accounting is unavailable rather than zero. No phantom provider/capability breakdown.
- [ ] Original-thought semantics: capture inference isolates the current original from unrelated events, memories and process metadata. Privacy redaction and bounded input remain. Live ordinary and privacy-topic originals are summarized about their actual subject.
- [ ] Setup: a compact beginner guide, storage location/privacy explanation, saving readiness independent of inference, explicit actual AI connection check using the real per-box budget; auth/nonreachable/limited/recovered states tested.
- [ ] UX: optional token settings, neutral empty draft, compact mobile capture, keyboard tabs, immediate post-auth refresh, persistent action feedback and correct project-map selection.
- [ ] Quality: deterministic production build despite inherited NODE_ENV; remaining reproducible API/UI defects, dead code and release compatibility warnings reviewed and fixed without broad unrelated refactors.
- [ ] Verification: RED/GREEN regression tests, full Python suite, TypeScript/build, browser/mobile/accessibility, true inference/error/retry/approval/restart and scratch-project/source-backed research journeys. Existing owner originals SHA-256 unchanged.
- [ ] Packaging: version 0.2.1 everywhere required, release notes/README quick start, clean isolated wheel install and retained frontend, checksums verified.
- [ ] Shipping: review actual diff, secrets and GitNexus detect_changes; explicitly stage reviewed files, commit/push; hosted Windows/Linux Python3.12/3.13 and release pipeline pass; read back public release/assets, download/verify all artifacts; final installed-version live test.

## Ownership and dependencies

Parent: backend setup contract/router, usage, attention completion, server/release quality, integration/live verification, docs/version/release. Frontend lane: DriftApp/ThoughtInbox/SetupGuide/SectionTabs/CSS and new UI-contract tests. Semantic lane: minimal Brain context hook, new capture context helper and tests. No overlapping edits, no child commits or remote writes.

GET /api/ui/setup returns version,capture_ready,storage_path,auth_required,free_only,shell_enabled,processing{state,message,model,checked_at}. POST /api/ui/setup/check returns the same shape after one explicit bounded admitted call. Both use existing authentication/origin middleware. Expected inference refusal/failure returns state unavailable/limited without destroying capture; never reveal secrets or raw upstream errors.

## Verification limitations

A green local suite is not the hosted matrix. Release only after real hosted checks. AI results remain advisory; source integrity is not independent fact checking. No monthly unattended/clinical guarantee. DMR-X and production Drift stay untouched unless a separately authorized deployment step is needed. Mutations use disposable boxes and scratch repositories; never copy owner thought text into shared evidence.
